# ESTRUCTURAS DE CONTROL EN PYTHON

Universidad San Lorenzo — Cátedra de Diseño de Algoritmos y Programación.
Resolución de los ejercicios prácticos de estructuras condicionales (`if`, `elif`, `else`) y repetitivas (`for`, `while`, `break`).

## Ejercicios incluidos
* `p1_mayor_tres_numeros.py`: Lee tres números enteros, indica si todos son iguales o muestra el mayor.
* `p2_calculadora_tarifas.py`: Calcula el monto a pagar según la edad y la tarifa base.
* `p3_promedio_calificaciones.py`: Calcula la media aritmética de `N` calificaciones y cuántas son `>= 6.0`.
* `p4_validacion_clave.py`: Valida una clave secreta con un límite de 3 intentos.
